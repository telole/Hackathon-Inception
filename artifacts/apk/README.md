# APK PakaianKita

PakaianKita-arm64-v8a.apk adalah build release khusus ARM64, terhubung ke Supabase presentasi. Build ini ditandatangani dengan debug signing configuration untuk instalasi pengujian tim, bukan distribusi Play Store.

Ukuran: 24089466 byte. Integritas file dapat diperiksa menggunakan SHA256SUMS.

Lihat ../../docs/presentation-demo.md untuk skenario dan daftar email akun. Password dibagikan terpisah.
